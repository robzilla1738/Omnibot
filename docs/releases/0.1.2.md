# Omnibot 0.1.2

This release improves upgrade safety, bot coordination, local terminals, and everyday editing.

**Requires macOS 12 or newer.** The bundled Sparkle framework has a macOS 12 deployment target. The published app metadata still says 11; that declaration was too low (also in 0.1.1). The signed update feed and documentation now use the actual requirement. Download bytes and checksums are unchanged.

## Before updating

Finish or stop running tasks, and send or copy any unsent drafts in your older app before restarting. Back up `~/.omni-bot/` if it contains important work. Keep the same data directory: the bundle identity, update feed and signing key are unchanged.

The first launch preserves an exact pre-migration store copy. Version 0.1.2 can recover a missing or damaged primary store from its backup and refuses unsupported newer schemas. Older binaries do not have that protection; follow the [recovery instructions](https://github.com/robzilla1738/Omnibot/blob/main/docs/recovery.md) before downgrading.

## Changes

- Embedded interactive terminals and retained run logs, stronger project/worktree isolation, bounded delegation, and scheduled-run grace periods.
- Drafts and composer selections survive navigation and restart; failed sends preserve newer edits. Saved reasoning defaults and skills launched from the library are respected.
- Git actions consistently target repository-relative files, including nested folders, staged additions and renames. Large previews and command output are bounded.
- Safer migration and backup recovery, preserved customized prompts, cleanup of leftover CLI helpers, and authenticated development connections.
- Fixes for stale Git previews, asynchronous avatar/profile updates, sidebar menu focus and Safari dialog keyboard navigation.
- Release artifacts tied to an exact source commit and successful CI run, with dependency audits and bundled license/notice provenance for 307 packages.

## Downloads and verification

The universal DMG and ZIP are Developer ID signed and Apple-notarized. The release includes SHA-256 checksums, a source/CI manifest, and dependency notices. Install the DMG by dragging Omnibot to Applications; existing signed installations can use Check for Updates.

Local verification passed 154 Rust tests, 69 Chromium tests, 69 WebKit tests and 23 Python safeguard tests, plus native startup, migration, restart persistence, PTY, update-check and active-task refusal checks. Release CI results are linked in the artifact manifest.

Apple Silicon native runtime was tested on macOS 27.0.1. Physical Intel, the minimum macOS 12, actual Sparkle older-to-newer installation/relaunch, and every live CLI/provider combination remain unverified. Both CPU architectures are included and inspected. Two scoped Rust lockfile advisories concern dependencies excluded from both shipped macOS graphs; CI verifies those exclusions. See the [support matrix](https://github.com/robzilla1738/Omnibot/blob/main/docs/support-matrix.md) and [security policy](https://github.com/robzilla1738/Omnibot/blob/main/SECURITY.md).
